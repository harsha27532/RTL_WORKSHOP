## 📖 About This Repo

Welcome to my **VSD RTL Design and Synthesis Workshop** repository. This repo tracks my session-by-session progress through the workshop — **RTL design**, simulation with **Icarus Verilog** and **GTKWave**, and synthesis with **Yosys** using the **SKY130** standard-cell library.

Each session has its own folder with a detailed README, the Verilog source/testbenches used, and screenshots from the labs.
